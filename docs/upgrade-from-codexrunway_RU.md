# Переход с CodexRunway

Новая идентичность — `com.quosparr.app`, `quosparr://` и `~/.quosparr`, поэтому старое приложение не может само обновиться до Quosparr. Закройте CodexRunway, установите Quosparr вручную и запустите его:

- При первом запуске копируются данные из `~/.codex-runway` и недостающие настройки. Старый каталог сохраняется, а при прерывании миграция безопасно продолжается.
- Пакеты аккаунтов, экспортированные под старым именем, по-прежнему можно импортировать; новые экспорты используют `quosparr-accounts`.
- Системные разрешения не наследуются. Добавьте виджеты рабочего стола заново и проверьте элемент входа. На macOS старый элемент входа, возможно, придётся удалить вручную в Системные настройки → Основные → Объекты входа.
- Миграция никогда не изменяет официальные файлы входа Codex / Grok.
