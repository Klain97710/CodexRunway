## 隔离更新验收

执行 `python3 Scripts/Tests/verify-update-proxy.py`，使用临时应用、测试密钥与隔离的安装目录；没有使用真实账号。

| 场景 | 结果 |
| --- | --- |
| 正确签名 | 版本 1 下载、解包、安装为版本 2，并重新启动 |
| appcast 被篡改 | 拒绝清单，无安装包下载；版本 1 保留 |
| 安装包签名错误 | 拒绝安装，版本 1 保留 |
| 有效签名但损坏的 ZIP | 解包失败，版本 1 保留 |
| 不可用的本机 HTTP 代理 | 检查失败，无安装包下载，版本 1 保留 |

四种失败场景均比较安装目录的内容指纹，确认原应用没有被替换；没有原作者更新源或直连回退。临时私钥在测试结束后删除。
