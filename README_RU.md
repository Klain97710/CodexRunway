# CodexRunway · Версия Klain97710

Версия **0.1.0 (1000)** для друзей и близких на основе [Licoy/CodexRunway](https://github.com/Licoy/CodexRunway). Включён только Codex. Русский интерфейс сохранён.

## Установка и обновление

1. Загрузите DMG из [Releases этого репозитория](https://github.com/Klain97710/CodexRunway/releases/latest): arm64 для Apple Silicon, x86_64 для Intel.
2. Закройте исходное приложение, сохраните копию приложения и настроек, затем замените его по прежнему пути. Аккаунты, Keychain, идентификаторы Widget и локальные данные сохраняются.
3. При установке через Homebrew сначала выполните `brew uninstall --cask codex-runway` без `--zap`, затем установите эту версию вручную.
4. Приложению нужна macOS 12+, виджетам — macOS 14+. Используется бесплатная подпись ad-hoc без нотариализации Apple. При первом запуске выберите «Открыть» в контекстном меню либо разрешите запуск в настройках конфиденциальности и безопасности.
5. Нажмите значок в строке меню, импортируйте текущий вход или войдите через браузер в настройках аккаунтов, затем обновите квоту.

После первой ручной замены обновления идут только из подписанного источника Sparkle этого репозитория. Установка требует подтверждения пользователя. При ошибке текущее приложение сохраняется. Для отката закройте приложение и верните его резервную копию, не удаляя аккаунты и сеансы.

Публичный статус сбросов включён по умолчанию с интервалом пять минут; уведомления и Widget сохранены. Ранее отключённая настройка остаётся отключённой. Реакции и идентификаторы посетителей удалены. Код Grok и старые файлы сохранены, но не используются; прежний выбор преобразуется в Codex.
